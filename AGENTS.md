# Рекомендации по проекту

## Обязательные skill'ы

Перед любыми изменениями кода агент обязан прочитать и применить три скилла:

- **`air-elt-overview`** — архитектура и формат конфигов.
- **`rust-guidelines`** — правила работы с Rust (раскладка модулей, naming, ownership, логирование).
- **`project-conventions`** — список общих утилит, которые обязательно использовать вместо ad-hoc реализации (`commons::sql::pg`, `commons::secrets`, `core::types`, `core::registry` и др.).

Если добавляется новая общая утилита — её нужно сразу задокументировать в `project-conventions`.

## Правила работы

* На каждую доработку (кроме тестов и метрик) пиши тесты.
* Всегда проверяй тесты после работы.
* Все версии библиотек всегда должны быть явно указаны.
* Избегай git-операций на апдейте.
* Инструкции для человека — в `README.md`.
* Инструкции и описание проекта для агентов — в `AGENTS.md` (этот файл) + три skill'а выше.
* Задания агентам ведутся в `agent_tasks/`.
* Если не работает Docker, проверяй podman; используй подман в первом приоритете.
* Удаляй все временные файлы, которые создаёшь.
* После каждой доработки вызывай `cargo fmt` и `cargo clippy --all-targets --workspace -- -D warnings`.
* `unsafe` в прод-коде запрещён — в workspace стоит `[workspace.lints.rust] unsafe_code = "deny"`. В тестах разрешено локальное `#[allow(unsafe_code)]` вокруг `std::env::set_var` (edition-2024 помечает его unsafe из-за race-with-reads), каждый такой блок обязан нести `// Why:` комментарий.
* Пропускать этапы из плана можно только с согласия пользователя.
* После выполнения задач запускай агентов-валидаторов (см. ниже).
* Используй лучшие практики для работы с rust.
* Добавляй файлы в `.gitignore`, если они временные или не нужны в гите.
* запускай скилы по расту, структуре проекта и по конвенциям в проекте перед выполнением задач (агента также должны их читать)
* после выполнения каждой задачи запускай агентов-валидаторов (см. ниже)

## Валидаторы после задач

Запускать параллельно:
`code-style-architect`, `architecture-reviewer`, `qa-auditor`, `business-feature-validator`, `ai-fraud-detector`, `protocol-db-validator`, `resource-overflow-auditor`, `resource-leak-validator`
